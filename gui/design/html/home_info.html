Information System for Modeling and Analysis of Optimal Control in Thermostatics

This program is designed to solve the optimal control problem for the thermostatics process in a one-dimensional rod under various initial conditions. The system allows working with both unconstrained control problems and problems where such constraints are present.

Solution methods

  • Gradient method for functional minimization
  • Conditional gradient method
  • Gradient method with adaptive discretization

The functional value is calculated using Simpson’s rule, ensuring high accuracy. The boundary-value problem is solved using the finite difference method followed by the application of the tridiagonal matrix algorithm (the Thomas algorithm).

User Guide

  • Adding a task: You can add a task via the "Add task" tab. The thermostatic problem conditions are predefined: the problem statement, functional, gradient, and basic parameters are displayed on the page. If you wish to keep a new solution for future reference, you must save it manually by clicking the "Save" button.
  • Method selection: You can choose a single method or perform a comparison between the classical and modified (gradient method with adaptive discretization) approaches.
  • History: All saved tasks can be viewed in the "History" tab.

Note:
